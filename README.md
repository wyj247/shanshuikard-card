# 一笔山水

输入一个名字 → 一幅水墨山水，含落款、题诗、钤印。纯代码生成，不用任何美术素材。
还能再出一张名片：同一幅山，右下角一个二维码。

## 用法

| 想做 | 双击 | 或命令行 |
| --- | --- | --- |
| 一张山水 | `生成.bat` | `python shanshui.py 名字 输出.png [seed]` |
| 只听名字的解读 | — | `python shanshui.py 名字 /tmp/x.png`（第一行会打印字象与题诗） |
| 一张名片 | `名片.bat` | `python card.py 名字 输出.png [seed] [url模板]` |
| 一个能发人的单文件网页 | — | `python export.py 名字 输出.html [站点根地址]` |
| 看样例 | `index.html` | — |

**同一个名字永远得到同一幅画**（名字经 CRC32 变成种子），所以名字本身就是这幅画的地址，
不需要数据库、不需要服务器、不需要图床。名片上的二维码写的就是这个地址。

## 网站

| 想做 | 双击 | 或命令行 |
| --- | --- | --- |
| 起一个站点 | `启动网站.bat` | `python site.py [端口]` |

打开 <http://127.0.0.1:8000> 就能用：写一个名字，页面直接给出山和名片。手机连同一个 WiFi，
用 `http://<内网 IP>:8000` 打开同一页；名片上的二维码编的就是这个地址，扫一下就到手机上同一座山。
第一次生成要 3~4 秒（numpy 现画），之后走 `_cache/` 缓存，秒开。

## 让「谁都能扫」

本地站点只在内网可达：`http://10.4.11.90:8000` 用的是私有地址，手机用 4G 打不开。
要让**任何人的手机**扫开，站点必须有一个公网地址。三种走法，都不改代码：

1. **有服务器 / 云主机**：把 `shanshui/` 传上去，`SHANSHUI_BASE=https://你的域名 python site.py 80`，
   前面挂一层 Nginx 反代即可。
2. **对象存储 / 静态托管**（OSS、COS、Vercel、GitHub Pages）：用 `export.py` 出单文件页面，
   可以把几千个名字一次性生成成静态目录，不用跑服务：
   ```
   python export.py 江雪 站点/江雪.html https://你的域名
   ```
3. **只发给别人看，不建站**：`export.py` 生成的是自包含 HTML（图在 base64 里），
   双击就开，微信/邮件发过去对方也能看，不需要服务器、不需要联网加载图。

名片上的二维码跟着地址走：`python card.py 名字 卡.png '' https://你的域名/?n={q}`
（第 3 个参数留空表示用默认种子）。

## 名字怎么变成画

名字先被「读」一遍：拆出里面的字象（水、木、山、日、月、雪、雨、云、舟、鸟、素、秋、春），
字象决定画面该有什么；认不出意象的字，交给 CRC32 种子去定。

| 字象 | 命中字（节选） | 画面 |
| --- | --- | --- |
| 水 | 江 河 清 溪 涵 涛 澜 湖 海 沙 温 洛 淮 | 水线上移（0.760H），八成有舟 |
| 木 | 林 松 柏 梅 枝 桐 柳 杨 枫 楠 榕 森 | 必有松 |
| 山 | 山 岳 峰 峦 岭 岩 峻 崖 岚 | 峰高 ×1.13，水线下移（0.815H） |
| 日 | 日 昭 曜 晖 昕 晨 曦 阳 旭 熙 暖 照 | 必画落日（且在山水之上） |
| 月 | 月 明 朔 望 朗 胧 | 必画淡月 |
| 雪 | 雪 霜 冰 寒 凝 | 水墨提亮、无日月、雾重、不画鸟 |
| 雨 | 雨 霖 霏 露 霭 | 下斜雨 |
| 云 | 云 霞 雯 霁 雾 | 起雾 |
| 舟 | 舟 帆 航 渡 船 | 必有舟 |
| 鸟 | 鸟 雁 鸿 鹤 鹏 燕 | 必有飞鸟 |
| 素 | 白 素 玄 墨 | 用墨色，不上彩 |
| 秋 | 秋 | 转赭石 |
| 春 | 春 | 转青绿 |

诗也跟着字象走：20 组五言／七言联里，挑与标签用字重合最多的；
同分时按种子抽，所以同一种意象也能出不同的诗。
反过来诗也会管画面——诗里有月，画上就有月；诗里下雨，天上就下雨；
画了落日，就不会配「明月松间照」这种句子。

```
python shanshui.py 江雪 out.png
→ [江雪] 字象=水、雪 · 诗=孤舟蓑笠翁／独钓寒江雪 · 1600×1000 · 雾 · 无
```

名字里一个意象字都没有时（比如 冯唐、无名氏），整幅画交给种子——文件名就是例子：
`冯唐.png`、`无名氏.png`（后者是立轴 1000×1400）。

## 每张图会变的维度

| 维度 | 取值 |
| --- | --- |
| 画幅 | 横幅 1600×1000 / 斗方 1250×1250 / 立轴 1000×1400 |
| 构图 | 山体主体偏左或偏右，题诗总在山的对面 |
| 配色 | 水墨 / 青绿 / 赭石 |
| 天气 | 晴 / 雾（大雾吞山）/ 雨（斜雨丝） |
| 日月 | 落日 / 淡月 / 无 |
| 点缀 | 舟、松、飞鸟各自有无，水线高低也有变化 |

## 名片

二维码默认内容是 `SHANSHUI/名字/种子`。扫出来这串，就能把同一座山重新画出来。
换成真链接只要给第四个数：

```
python card.py 林清和 卡.png 7 "https://你的域名/?n={q}"
```

`{q}` 是 URL 编码后的名字。上线时把域名换掉，二维码里就是可点的网址。

## 二维码是自己写的

`qr.py` 不依赖任何第三方库：字节模式、版本 1–10、纠错 L/M/Q/H、
Reed-Solomon、8 种掩码按罚分择优、格式信息与版本信息的 BCH 码，全部手写。

自检（`python test_qr.py`）：

- v1–v10 的数据模块数逐一等于规范值（208 / 359 / 567 / 807 / 1079 / 1383 / 1568 / 1936 / 2336 / 2768）——
  这一项证明定位图形、时序图形、校正图形、版本信息区、格式信息区的位置和数量全对。
- 编解码往返一致，且每块纠错码字的校验子全为零。
- 格式信息常数 5412 / 77C4 / 355F / 1689、版本信息 07C94 / 085BC、
  以及 n=7 和 n=10 的 RS 生成多项式，都与公开表逐项吻合。
- 另外用 api.qrserver.com 的参考实现逐模块比对过 v1 / v5 / v7，三个版本完全一致。

拿到一张名片，还可以验一验它到底扫不扫得出来：

```
python verify_scan.py 林清和 江雪
```

它把名片上的二维码裁下来，降到 45%/55%/70% 三档清晰度，加高斯模糊、压成 JPEG，
再按模块中心从像素读回矩阵，用 Reed-Solomon 校验挑出正确的（纠错级，掩码）组合，最后比对载荷。
3 个名字 × 3 档清晰度 × 3 种对位偏移 = 9 格，实测全过（名片是 6–7 像素/模块、4 模块静区）。

## 原理（全部是算法）

| 画面元素 | 算法 |
| --- | --- |
| 山脊轮廓 | 若干宽度、偏度、指数各异的峰体 `exp(-|dx/w|^p)` 相加，归一化后取 `acc**0.92` |
| 远近五层 | 由远及近，色由浅入深，透明度 0.34 → 0.94 |
| 墨色不匀 | 值噪声（小网格随机数 + 平滑插值）乘进墨色 |
| 皴擦 | 沿山脊切线方向撒数百条短笔，离脊线越远越淡 |
| 云气 | 以山脚为中心的高斯横带，中心线随一维噪声起伏，再用二维噪声撕碎 |
| 水面 | 起伏的水平线以下做竖向渐变，加横线水纹 |
| 松、舟、飞鸟、苔点 | 矢量笔画（线段、圆弧、椭圆） |
| 题诗 | 内置 20 组联句，按字象打分选，竖排；字带纸色描边，压在山上也读得清 |
| 钤印 | 名字末字，朱红方印 + 干支纪年「丙午冬」 |
| 纸感 | 高斯噪点 + 径向暗角 |

## 依赖

Python 3 + numpy + Pillow，字体用 `C:\\Windows\\Fonts\\simkai.ttf`（找不到会逐级回退）。二维码不需要额外依赖。

## 已知局限

- 皴笔是"沿坡撒短擦"，还没有笔毫分叉、枯湿浓淡，近看仍偏机械。
- 没有真笔锋，山石的质感和真迹比还差一个层级。
- 二维码在深色山体上靠一块纸色底板承托；如果哪天做成透明贴纸，要保证静区（四周留白）够宽。
